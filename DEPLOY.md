To run:

F5 — builds and launches with the debugger attached (you'll see breakpoints, exceptions, etc.)
Ctrl+F5 — builds and runs without debugger (faster)
Ctrl+Shift+B — build only



This is a .NET 8 WPF project. You can compile it using the .NET CLI or Visual Studio:

Using the .NET CLI (command line):


dotnet build
For a release build:


dotnet build -c Release
To build and run directly:


dotnet run
