


This is a client-side video player, which works primarily against a bookmarks service.

The bookmarks service is cloudflare based, with an API. 

When absolutely necessary for debugging you may read-only investigate that project-
D:\Projects\playlist

## UI / styling

The desktop client (`app-flyleaf/`) uses the "Indigo Slate" dark theme. See
[STYLE-GUIDE.md](STYLE-GUIDE.md) for the palette, typography, shared control styles, and the
mandatory thin dark scrollbar (`ThinDarkScrollBar`) that every scrollable list must apply.
